# DJI 电机应用示例

> 文档类型：应用示例
> 适用范围：通过 ECAT2CAN 验证 DJI 电机 CAN 报文和反馈链路
> 状态：可选，不属于 ECAT2CAN 主站核心功能

## 1. 用途和边界

`motor_pos` 用于验证以下链路：

```text
主机 EtherCAT PDO → ECAT2CAN 从站 → CAN → DJI 电机/电调
主机 EtherCAT PDO ← ECAT2CAN 从站 ← CAN ← DJI 电机/电调反馈
```

示例支持：

- M3508 + C620：电流指令模式；
- GM6020：电流指令模式或电压指令模式；
- 1 ms 周期的位置环和速度环；
- 反馈监视、开环测试和基本安全联锁。

主站协议、从站状态机、CAN 链路测试和实时性基准请查看项目根目录的 `README.md` 及 `docs/` 其他文档。本示例不应替代专用的产品级电机控制器。

## 2. 代码和构建

| 文件 | 职责 |
| --- | --- |
| `src/motor_control.h` | 电机类型、反馈状态、PID 状态、故障类型和单位约定 |
| `src/motor_control.c` | DJI CAN ID、反馈帧解码、编码器回绕、量程换算和 PID 实现 |
| `src/motor_pos.c` | SOEM 初始化、终端交互、PDO 组包、1 ms 调度和安全联锁 |

默认使用 CMake 构建：

```bash
cmake --preset default
cmake --build --preset default
```

构建后程序位于 `build/motor_pos`。运行 EtherCAT 需要原始套接字（raw socket）权限，具体设置方式见主 README。

## 3. 前置条件

开始控制前确认：

1. 网关、CAN 总线和电机已经正确供电，EtherCAT 网线接在网关的 Port0；
2. 电机已经固定，输出轴附近没有人员和易损部件；
3. 已确认 Linux 网卡名、CAN 通道和 DJI 电机 ID；
4. GM6020 使用电流模式时，固件至少为 `1.0.11.2`，并在 RoboMaster Assistant 中打开“电流环开关”。

程序启动后默认失能，必须输入 `e` 并回车才允许输出。首次连接应先使用 `--monitor`。

## 4. 快速验证

将 `<网卡名>` 替换为实际 EtherCAT 网卡，例如 `enp3s0`。

### 4.1 只读监视

只接收反馈，不发送有效电机指令：

```bash
./build/motor_pos <网卡名> --motor m3508 --ch 0 --id 1 --monitor
```

手动转动电机，确认位置、转速、温度和错误码能够更新。出现 `(等反馈)` 时不要使能。

### 4.2 M3508 + C620

```bash
./build/motor_pos <网卡名> --motor m3508 --ch 0 --id 1 --limit 1
```

在确认电机固定后，依次输入：

```text
e       使能，目标先设为当前位置
c 1     以 1 A 做小幅开环测试
c -1    反向测试
c 0     退出开环，回到位置闭环
2       将输出轴目标设为 2°
d       失能
q       退出
```

### 4.3 GM6020

默认使用电流模式：

```bash
./build/motor_pos <网卡名> --motor gm6020 --ch 0 --id 1 --limit 1
```

如果电流模式没有响应，可改用电压模式：

```bash
./build/motor_pos <网卡名> --motor gm6020 --ch 0 --id 1 --gm-voltage --limit 3000
```

## 5. 命令行参数

### 5.1 通用参数

| 参数 | 单位/取值 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `--motor` | `m3508` 或 `gm6020` | `m3508` | 选择协议类型 |
| `--ch N` | CAN 通道 `0~3` | 构建配置值，通常为 `3` | ECAN-Lite：CN4=0、CN5=1、CN9=2、CN1=3；单路版通常只有 3 |
| `--id N` | M3508：`1~8`；GM6020：`1~7` | `1` | 电机或驱动器 ID |
| `--ratio F` | 转子转数/输出轴转数 | M3508：`19.2032`；GM6020：`1` | 不带减速箱的 M3508 使用 `--ratio 1` |
| `--gm-current` | 开关 | 开启 | GM6020 使用电流模式；默认已开启，通常无需显式指定 |
| `--gm-voltage` | 开关 | 关闭 | GM6020 使用电压模式，与 `--gm-current` 互斥 |
| `--target F` | 输出轴角度，° | `0` | 初始目标位置 |
| `--limit F` | A 或原始计数 | 见 5.2 | 输出限幅，可用运行时命令 `m` 修改 |
| `--max-rpm F` | 转子 rpm | `2000` | 位置环输出的转速限幅 |
| `--invert-spd` | 开关 | 关闭 | 反转反馈转速符号；仅在确认符号约定相反时使用 |
| `--monitor` | 开关 | 关闭 | 只读监视，禁止使能并强制输出为零 |
| `--log-ms N` | 毫秒 | `200` | 非交互输出时的状态打印周期 |
| `--filter-ms N` | 毫秒 | `5` | 反馈低通时间常数；`0` 表示关闭 |

### 5.2 输出量和限幅

`--limit` 的单位取决于电机类型和 GM6020 模式：

| 电机和模式 | 输出量 | 协议满量程 | 默认 `--limit` |
| --- | --- | ---: | ---: |
| M3508 + C620 | 转矩电流 | ±20 A | 3 A |
| GM6020 电流模式 | 转矩电流 | ±3 A | 1 A |
| GM6020 电压模式 | 原始计数 | ±25000 | 3000 |

### 5.3 PID 和可选电流环

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `--pos-kp/--pos-ki/--pos-kd` | M3508：`8/0/0`；GM6020：`4/0/0` | 位置环增益，误差单位为输出轴角度 |
| `--spd-kp/--spd-ki/--spd-kd` | M3508：`20/0.2/0`；GM6020：`4/0.05/0` | 速度环增益，速度反馈单位为转子 rpm，输出为原始计数 |
| `--cur-loop` | 关闭 | 启用主机侧电流环，仅用于对比实验 |
| `--cur-kp/--cur-ki` | `0.3/0.02` | 主机侧电流环增益 |

驱动器已经提供高速电流环，通常不需要启用 `--cur-loop`。主机侧电流环受 EtherCAT 和 CAN 往返延迟影响，默认关闭。

## 6. 运行时命令

命令输入后必须按回车。

| 命令 | 作用 |
| --- | --- |
| `e` | 使能；同时把目标位置设置为当前位置并清零 PID 状态 |
| `d` | 失能并退出开环模式，输出为零 |
| `z` | 将当前位置设为零点，目标位置设为 `0°` |
| `s` | 将目标位置设为当前位置，用于软停 |
| `<数字>` | 设置输出轴目标角度，例如 `90` 或 `-45.5` |
| `c <值>` | 开环输出，单位同 `--limit`；`c 0` 返回位置闭环 |
| `m <值>` | 修改输出限幅，单位同 `--limit` |
| `kp/ki/kd <值>` | 在线修改位置环增益 |
| `skp/ski/skd <值>` | 在线修改速度环增益 |
| `g` | 打印当前增益、限幅和目标位置 |
| `?` | 显示命令帮助 |
| `q` | 退出程序，并发送一段零输出 |

## 7. DJI 报文和反馈定义

### 7.1 控制和反馈 CAN ID

| 项目 | M3508 + C620 | GM6020 |
| --- | --- | --- |
| 控制帧 | `0x200`：ID 1~4；`0x1FF`：ID 5~8 | 电压模式：`0x1FF`/`0x2FF`；电流模式：`0x1FE`/`0x2FE` |
| 反馈帧 | `0x200 + ID`，即 `0x201~0x208` | `0x204 + ID`，即 `0x205~0x20B` |
| 控制帧数据 | 4 个大端 `int16` | 4 个大端 `int16` |

同一个 `0x1FF` 在 C620 和 GM6020 中含义不同，程序根据 `--motor` 自动选择。不要在同一条 CAN 总线上配置会发生 ID 冲突的设备。

### 7.2 反馈帧 8 字节布局

| 字节 | 内容 | 用途 |
| --- | --- | --- |
| `[0..1]` | 机械角度，`0~8191` | 位置环；程序按 8192 计数回绕并累计多圈角度 |
| `[2..3]` | 转子转速，rpm | 速度环 |
| `[4..5]` | 实际转矩电流或原始反馈量 | 监视，可选用于主机侧电流环 |
| `[6]` | 温度，℃ | 过温保护 |
| `[7]` | 错误码 | C620 故障保护；GM6020 通常为保留值 |

### 7.3 控制链路

```text
输出轴角度 → 位置环 → 转子目标转速 → 速度环 → 电流/电压指令
                                                    ↓
                                           驱动器内部电流环 → 电机
```

位置环和速度环在主机侧以 1 kHz 运行。GM6020 直驱且惯量较小，默认增益低于带减速箱的 M3508。

## 8. 状态栏和诊断

交互终端底部两行显示运行状态；重定向到文件时会退化为逐行输出：

```bash
./build/motor_pos <网卡名> --motor m3508 --ch 0 --id 1 --monitor --log-ms 100 > run.log
```

状态栏主要字段：

| 字段 | 含义 |
| --- | --- |
| `位置 当前 → 目标` | 输出轴当前角度和目标角度 |
| `电流 实测/指令` | 有安培量程时显示 A，否则显示原始计数 |
| `转速 当前[目标]` | 反馈转速和速度环输出的目标转速 |
| `℃` | 电机反馈温度 |
| `E` | 驱动器错误码 |
| `us` | 最近一次 EtherCAT 往返耗时 |
| `(等反馈)` | 尚未收到有效电机反馈 |

常见现象：

| 现象 | 检查方向 |
| --- | --- |
| 使能后没有反馈 | 检查电机供电、CAN 接线、通道和 `--id` |
| GM6020 电流模式无响应 | 确认固件版本和 RoboMaster Assistant 的电流环开关；也可临时使用 `--gm-voltage` |
| 指令有值但实测电流接近零 | 检查驱动器模式、电机三相线和反馈 ID |
| 位置误差持续增大 | 立即输入 `d`，检查方向；确认后使用 `--invert-spd` 重试 |
| 输出频繁换向或高频抖动 | 降低速度环 `skp`，再降低位置环 `kp`，并保留适当的 `--filter-ms` |

## 9. 首次上电流程

每一步都应确认电机已固定。

1. 使用 `--monitor` 启动，手动转动电机，确认反馈角度、转速和温度正常；
2. 使用小限幅（M3508 建议 `--limit 1`，GM6020 电流模式建议 `--limit 0.5`）启动；
3. 输入 `e`，确认目标自动跟随当前位置，电机不会突然跳动；
4. 使用 `c 1` 或更小值做短暂开环测试，确认正方向与位置读数增加方向一致；
5. 输入 `c 0`，发送小目标，例如 `1` 或 `2`，观察位置闭环；
6. 确认稳定后再逐步提高 `--limit` 和 `--max-rpm`。

## 10. PID 整定建议

默认参数只用于示例和初步验证，实际值取决于负载、减速箱、摩擦和安装刚度。

### 10.1 速度环

先退出开环并关闭位置环比例：

```text
c 0
kp 0
e
```

手动转动后松手观察：

- 回弹慢、阻尼不足：逐步增加 `skp`，每次约为原值的 1.5 倍；
- 抖动或嗡鸣：降低 `skp`；
- 稳态存在小偏差：少量增加 `ski`。

### 10.2 位置环

速度环稳定后，从较小的目标角度开始：

```text
kp 4
2
```

- 到位慢：增加 `kp`；
- 超调或往返摆动：降低 `kp`，必要时少量增加 `kd`；
- 高频抖动：先降低 `skp`，再降低 `kp`，并确认没有关闭反馈滤波。

程序检测到 0.2 s 内输出换向超过 30 次时会提示疑似自激。此时先输入 `d`，降低 `skp` 和 `kp` 后重新使能；必要时将 `--filter-ms` 从 `5` 增加到 `10` 或 `20` ms。滤波越强，响应延迟也越大。

## 11. 安全机制

以下条件会自动失能并将输出置零：

| 机制 | 阈值或行为 |
| --- | --- |
| 反馈超时 | 超过 `100 ms` 未收到有效反馈 |
| 过温 | 温度达到 `100 ℃` |
| 驱动器故障 | 反馈错误码非零 |
| 闭环发散 | 位置误差连续增大约 `0.5 s` |
| 输出限幅 | `--limit` 或运行时 `m` 命令 |
| 转速限幅 | `--max-rpm` |
| 目标角度限幅 | ±`7200°` |
| 监视模式 | `--monitor` 始终禁止使能 |

退出时程序会先发送 100 个周期的零输出，再将 EtherCAT 从站切回 INIT 并关闭网卡。
